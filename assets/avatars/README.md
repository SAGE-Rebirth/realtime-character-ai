# Avatars

The playground ships with a built-in procedural character, so no files are needed.

To try your own model, drop a `.vrm` file (VRM 0.x or 1.0) onto the playground stage. Free sources:
[VRoid Studio](https://vroid.com/en/studio) (make your own) or CC0/CC-BY models whose licence allows
your use. `.vrm` files here are git-ignored; keep licences next to any model you add.
